# Implementation of an Interactive Tool with a Graphical User Interface for Evaluation of System Performance Measures

BSc thesis by **Danijel Askov**, University of Belgrade, School of Electrical Engineering.
Mentor: prof. dr Jelica Protić.

📄 **[Read the thesis (PDF)](askov-2026-bsc-thesis.pdf)** — written in Serbian (Cyrillic).

## Abstract

This thesis presents a cross-platform educational software tool with a graphical user interface for easy, interactive creation of queueing system models and for evaluation of their performance measures using (1) discrete-event simulation and (2) well-known analytical methods. In addition, a “what-if” analysis is implemented, which lets the user gain insight into how changes to particular model parameters affect the system’s performance measures.
